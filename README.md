# Zero Parades — Inventory Filter

**Version 1.0.0** · BepInEx 6 IL2CPP · .NET 6 · Windows

A compact, dossier-style inventory filter for **Zero Parades**. Filter clothing and tools by the skill bonuses they provide, without changing item ownership, equipment, or save data.

## Features

- **ALL, Clothing, and Tools:** choose one of the 15 skills to show items that grant a **positive** bonus to that skill.
- **Drugs:** deliberately unfiltered; drugs are not indexed by fatigue/stress/status effects.
- **Other:** unfiltered in its own category.
- **NO FILTER:** restores the full native list, including **Recently Added**, while preserving scrolling.
- **Automatic focus:** after observing a normal manual item-cell selection, the plugin can focus a compatible item via Unity's native `Selectable.Select()` pathway. This is **selection**, not equipping or using the item. If the selection cannot be verified, automatic attempts are disabled for the rest of that game session.
- **Native appearance:** a compact selector with the game's visual palette; it temporarily hides when you hover native inventory-category icons so their tooltips remain readable.
- **No floating double image:** hides the separate enlarged selected-item artwork over the inventory grid; normal item cells and the right-hand detail illustration are retained.
- **Fast UI updates:** cached inventory cells, a short refresh cadence while filtering, reused temporary collections, and one deferred scroll-layout refresh after items are restored.

Items with unreadable/unknown modifier data are left visible rather than silently hidden. No item is destroyed, duplicated, or moved by the filter.

## Requirements

- Zero Parades, tested on **Unity 6000.3.15f1**.
- **BepInEx 6 IL2CPP** installed and launching correctly.
- The game and interop assemblies generated by your local BepInEx installation.

## Installation

1. **Close the game. Back up a healthy save** before changing mods.
2. Remove any previous `ZeroParadesClothingFilter.Rebuilt.dll` and **old** `ZeroParadesInventoryFilter.dll` from `BepInEx/plugins`. Do not keep two versions installed at once.
3. Copy `plugins/ZeroParadesInventoryFilter.dll` from this archive into `<Zero Parades>/BepInEx/plugins/`.
4. **Existing installation:** keep `BepInEx/config/zp.inventory.filter.cfg` to preserve your UI offsets and preferences. **Fresh installation:** optionally copy `config/zp.inventory.filter.cfg` to `BepInEx/config/`, or let BepInEx generate the configuration on first launch.
5. Start the game and look for `Inventory Filter v1.0.0 loaded` in `BepInEx/LogOutput.log`.

If you want a completely clean configuration after upgrading, **first back up your existing `.cfg`**, then replace it with the sample configuration. Obsolete experimental keys in an older `.cfg` are ignored; they do not reactivate removed diagnostic or deduplication code.

## Using the filter

Open Inventory and choose a skill from the selector above the category icons. Switch between ALL, Clothing, and Tools; the selected skill persists. Return to **NO FILTER** to see the complete native inventory. The selector is absent on Drugs, which remains unchanged.

The game's **Recently Added** cells are deliberately kept. This prevents the empty-inventory regression seen in experimental visual deduplication builds.

## Configuration

See `config/zp.inventory.filter.cfg` for a complete commented sample. Important settings:

| Setting | Default | Purpose |
|---|---|---|
| `Enabled` | `true` | Master switch |
| `EnableVisualFiltering` | `true` | Hide nonmatching cells visually |
| `EnableAllTabVisualFiltering` | `true` | Filter the ALL tab |
| `EnableToolsTabVisualFiltering` | `true` | Filter the Tools tab |
| `EnableSafeAutoSelectionTrial` | `true` | Enable verified native UI focus after observing manual selection |
| `InheritCanvasSorting` | `true` | Use native inventory draw ordering |
| `YieldToTabTooltips` | `true` | Hide closed selector while a native category tooltip is requested |
| `HideFloatingSelectedArtwork` | `true` | Hide enlarged grid-hover selected-item art |
| `OriginalStyleOffsetX`, `OriginalStyleOffsetY` | `56`, `-24` | Fine-tune position (same default as 0.2.5) |
| `FontAssetName` | empty | Auto-detect the game readout font |

`EnableSafeAutoSelectionTrial` retains its **legacy key name** for backward-compatible settings; it is the normal verified auto-selection feature in v1.0.0.

## Safety and limitations

- The plugin observes existing **UI ItemCells** and applies **CanvasGroup / LayoutElement** visibility; it does not patch game methods with Harmony, directly modify inventory collections, equip/consume items, or interact with save objects.
- Native UI selection may still trigger the game's own selection callbacks. **No mod can guarantee compatibility with every game update or save.** Keep a save backup before trying new game builds or other inventory mods.
- Unknown stat data is kept visible as a safety fallback; this can include an item that cannot be confidently classified.
- No filtering by item type, item name, fatigue, or status effects is provided.

## Troubleshooting

**The inventory seems empty:** choose NO FILTER. If it remains empty, disable `EnableVisualFiltering`, restart, and check whether an older DLL is installed beside this release.

**Automatic selection does not move the highlight:** manually select an inventory item once, then change skill. If native selection verification fails, the plugin stops further automatic attempts for that session; restart to retry. The visibility filter can still work independently.

**The selector overlaps a tooltip:** leave `InheritCanvasSorting = true` and `YieldToTabTooltips = true`.

**Need the game's original floating artwork:** set `HideFloatingSelectedArtwork = false` and restart.

**Scroll or layout problems:** switch to NO FILTER; the plugin schedules a deferred native layout refresh. If the issue persists, roll back to your known-good DLL and provide your `LogOutput.log`.

**Rollback:** close the game, remove v1.0.0 DLL, and restore your backed-up, known-good **Inventory Filter v0.2.5** DLL and configuration. Do not install both concurrently.

## Building from source

The complete C# project is in `source/`. With the game and BepInEx 6 IL2CPP installed, open PowerShell:

```powershell
cd <path-to-extracted-archive>\source
.\Build.ps1 -GameDirectory 'E:\Programas\Steam\steamapps\common\Zero Parades'
```

Use **.NET SDK 6** or another compatible SDK. The `.csproj` resolves references from `<GameDirectory>/BepInEx/core` and `BepInEx/interop`. Find the built DLL in the Release folder printed by the script.
